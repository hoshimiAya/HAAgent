## 二、每个文件的作用

### `CMakeLists.txt`

**作用**：告诉 CMake 怎么构建这个项目。

**关键内容**：
- `project(<项目名> ...)` — 定义项目名和版本
- `add_executable(...)` / `add_library(...)` — 定义构建目标
- `install(...)` — 安装规则

**什么时候改**：
- 加新源文件 → 加到 `add_executable` / `add_library` 里
- 加依赖库 → 加 `find_package` + `target_link_libraries`
- 加测试 → 加 `enable_testing()` + 测试目标

---

### `CMakePresets.json`

**作用**：把一长串 CMake 命令行参数存成 JSON，用 `--preset 名字` 一键调用。

**关键内容**：
- `generator` — 用哪个构建系统
- `CMAKE_TOOLCHAIN_FILE` — 指向 vcpkg，让 vcpkg 生效
- 各预设（debug / release）

**什么时候改**：
- 加新平台
- 改构建目录位置
- 改生成器

---

### `vcpkg-configuration.json`

**作用**：声明 vcpkg 用哪个注册表、哪个基线版本。
`default-registry` 指定主注册表和 baseline，`registries` 可以加额外的 artifact 注册表。
一般由 `vcpkg new` 生成，不需要手动改；升级 vcpkg 版本时改 `baseline`。


**什么时候改**：
通过 `vcpkg new --application` 生成，通常不需要改。

---

### `vcpkg.json`

**作用**：声明项目依赖哪些第三方库。

**关键内容**：
- `name` — 项目名（清单模式必须）
- `version` — 项目版本
- `dependencies` — 依赖列表
- `builtin-baseline` — vcpkg 版本基准

**什么时候改**：
通过 `vcpkg add port name` 添加新依赖

---

### `.gitignore`

**作用**：告诉 Git 哪些文件不要跟踪。

---

### `.gitattributes`

**作用**：告诉 Git 怎么处理换行符。

---

### `README.md`

**作用**：项目门面，说明项目是什么、怎么构建。

**什么时候改**：项目目标、构建方式变化时。

---

### `docs/项目结构说明.md`

**作用**：本文件。说明每个配置文件的用途与维护方式。

**什么时候改**：项目结构变化时。
